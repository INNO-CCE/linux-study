# 嵌入式/Linux 方向研究生三年学习与求职规划

> **适用对象**：信息工程本科、电子信息工程专硕、有 C 语言和单片机基础，研一，目标嵌入式 Linux 开发。
> **规划起点**：2026 年 10 月。
> **时间假设**：三年制专硕，2029 年毕业，2028 年秋招。

------

## 0. 目标与核心策略

### 总目标

- 研一：补齐 Linux 系统编程、工程工具链、驱动入门，完成第一个嵌入式 Linux 项目。
- 研二：确定细分方向，完成高质量项目，拿到大厂暑期实习并争取转正。
- 研三：秋招进入嵌入式 Linux 相关岗位。

### 核心策略

1. **项目驱动，不要等“学完”再做。**
2. **输出倒逼输入**：代码 + GitHub + 技术博客 + 项目文档。
3. **尽早实习**：日常实习 → 大厂暑期实习 → 秋招。
4. **围绕岗位要求学习**：C/C++、Linux 系统编程、驱动、ARM、调试、协议。

## 2. 研一上：2026.10—2027.1

### 2026.10：Linux 环境 + C 进阶 + 工具链

- **C 语言进阶**
  - 指针、函数指针、内存布局、结构体对齐。
  - 链表、队列、栈、哈希表基础。
- **Linux 环境**
  - Ubuntu、VSCode + SSH、终端常用命令。
  - Git：add/commit/branch/merge/remote。
  - GCC、Makefile、GDB。
- **产出**
  - GitHub 仓库 1 个。
  - 多文件 C 项目，能用 Makefile 编译、GDB 调试。

### 2026.11：Linux 系统编程

- 文件 I/O、进程、线程、进程间通信、Socket。
- 重点：`fork`、`exec`、`pthread`、`pipe`、`mmap`、`select/poll/epoll`。
- **产出**
  - 多线程 TCP 文件服务器 / 聊天室。
  - 技术博客 2—3 篇。

### 2026.12：ARM 体系 + 字符设备驱动入门

- 复习 STM32：中断、DMA、I2C、SPI。
- ARM 体系：寄存器、异常、中断、MMU 基础。
- Linux 驱动入门：
  - 内核模块编写、编译、加载、卸载。
  - `file_operations`、字符设备注册。
  - 设备树基础。
- **开发板建议**
  - 正点原子 i.MX6ULL、野火 i.MX6ULL、树莓派。

### 2027.1：第一个驱动项目

- GPIO LED、按键中断、I2C 温湿度传感器。
- **产出**
  - 字符设备驱动 + 设备树 + 用户态测试程序。
  - 项目 README 与调试记录。

## 3. 研一下：2027.2—2027.6

### 2027.2—3：驱动进阶

- platform 驱动、输入子系统、I2C/SPI 子系统。
- 并发控制：自旋锁、互斥锁、信号量、原子操作。
- 中断下半部：tasklet、工作队列、threaded IRQ。
- **产出**
  - 一个 platform 驱动项目。
  - 一个 I2C/SPI 传感器驱动。

### 2027.4：系统移植

- U-Boot 移植与裁剪。
- Linux 内核配置、编译、裁剪。
- 根文件系统：BusyBox、Buildroot、Yocto。
- **产出**
  - 从零构建可启动的嵌入式 Linux 系统。

### 2027.5：综合项目 + 简历 + 投日常实习

- 综合项目选题：
  - 智能家居网关。
  - 数据采集网关。
  - 视频监控。
- 简历：项目按 STAR 法则写。
- 投递：中小厂、初创公司嵌入式软件/驱动实习。

### 2027.6：面试与完善

- 复习 C、Linux、驱动、网络、OS。
- 补 FreeRTOS：任务调度、信号量、队列。
- **产出**
  - 1—2 个可展示项目。
  - 第一份实习面试记录与复盘。

## 10. 技能优先级

## 12. 避坑清单

1. 不要一直停留在 STM32 裸机，除非确定走 MCU 方向。
2. 不要只看视频不动手，驱动必须自己编译、加载、调试。
3. 不要忽略 Git、Makefile、GDB 等工程工具。
4. 不要等“完全准备好”才投实习，边投边补。
5. 不要只做教程项目，要有自己的扩展和思考。
6. 尽早和导师沟通就业意向，把实验室项目往嵌入式/边缘计算靠。
7. 保持英文阅读，芯片手册和内核文档是重要信息来源。
